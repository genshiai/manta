## 凡例

| タグ | 意味 |
|------|------|
| **P1** | Phase 1 MVP — 外来1ループに必須 |
| **P2** | Phase 2 — 診療支援拡充 |
| **P3** | Phase 3 — 入院・病棟・AI |
| **P4** | Phase 4 — 病院全体・マルチテナント |
| **--** | 対象外（ハードウェア依存・レガシー前提等） |
