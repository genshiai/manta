## karte-b.html の見方

- 上部セグメントで **読む / 並べる / 書く / 作業 / 入院** の5状態を切替（←→キー対応）
- 「読む」選択時のみ、直下に **AIサマリーの見せ方（A 1行 / B AIOカード / C ブリーフィング / D 対話型）** のサブ切替が出る
- モック内の臨床画面は**ライト基調で固定**（閲覧ページ自体はライト/ダーク両対応）
- 実寸 1440×860 を縮小表示。患者名・患者 ID・数値はすべて架空のデモデータで、実在の人物・医療機関とは関係ない
