## 実装単位の詳細

### 3.7 ICD10 病名ツール

- backend
  - 標準病名 master table
  - 索引 / 同義語 master table
  - 病名検索 API
  - 患者 problem に `icd10_code`、`diagnosis_type`、`management_number` を保持
  - 次: 履歴 master の実データ import、廃止病名移行 UI
- frontend
  - 病名検索 input
  - 候補一覧
  - 主病名 / 副病名 / resolved 切替
  - 同義語ヒット
  - 次: 病名移行候補表示
- 完了条件
  - 病名を検索して problem に追加できる
  - problem から ICD10 コードが参照できる

### 6.1 処方の検索性・過去処方複写

- backend
  - 処方履歴 API
  - 薬歴タイムライン API
  - 前回処方複写プレビュー API
  - 前回処方一括複写 API
  - 候補検索 query
  - 薬剤 master CSV import
  - HOT/YJ 継続 import CLI
  - FHIR MedicationRequest export / search
  - 処方追加時の安全警告返却
- frontend
  - 薬剤検索欄
  - 既存処方からの入力複写ボタン
  - 前回処方をまとめて再利用するボタン
  - 複写前プレビューと差分表示
  - 処方セット展開前プレビュー
  - 重複・病名関連の差分表示
  - 薬剤別の長期サマリ
  - 処方追加後の警告件数表示
  - 次: 前回処方セット複写
- 完了条件
  - 候補を検索して追加できる
  - 直近処方をまとめて再利用できる

### 24.1 / 24.3 時系列参照

### 25.1 / 25.6 セット / テンプレート管理

- backend
  - 処方セット master

  - template admin CRUD
- frontend
  - settings に template tab
  - settings に処方セット tab
  - chart で複合セットを再帰展開
  - chart で処方 / 検査セットの展開前プレビュー
  - chart にセット展開導線
