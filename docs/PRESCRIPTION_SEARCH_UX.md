# 処方検索 UX 方針

Manta の処方検索は、`正本 master をローカル DB に持つ` ことを前提に、入力中の負荷を最小化する。

更新日: 2026-04-28

## 目標

- 名前を打ち始めた瞬間に候補が出る
- 一度使った薬は次回もっと上に出る
- 同じ患者で継続しそうな薬はさらに上に出る
- 選んだら用法が自動で入る
- 必要なら PMDA の詳細にすぐ飛べる

## サジェスト順位の原則

1. コード完全一致
2. 商品名前方一致
3. 一般名前方一致
4. カナ前方一致
5. 病名関連一致
6. 個人の利用履歴による補正
7. 同一患者の直近処方による補正

## 学習させるシグナル

- `selected_count`
  - 候補として選んだ回数
- `prescribed_count`
  - 実際に追加した回数
- `last_selected_at`
- `last_prescribed_at`

## Manta の段階的実装

### 現在

- 薬剤検索欄
- カテゴリ絞り込み
- 候補クリック
- 既定用法の自動入力
- 現在処方からの入力複写
- ローカル利用履歴による順位補正
- `generic / brand / kana / code / alias` の横断検索
- 処方セットの登録と呼び出し
- 薬剤 master CSV import
- HOT / YJ 正本データの継続 import
- YJ コードからの PMDA リンク自動生成
- 薬歴タイムライン API
- 薬剤別の長期サマリ
- 複写前プレビュー
- 前回 / 今回の処方差分表示
- 処方セット展開前プレビュー
- 前回処方をまとめて再利用
- 複写時の本日重複 / アレルギー系スキップ

### 次

- 前回処方セット複写

### 後続

- 患者群・診療科別のおすすめ候補
- 安全情報の構造化チェック

## UX の細かい約束

- 候補は 5〜8 件に絞る
- 1 候補あたりで見せる情報は絞る
  - 薬剤名
  - 区分
  - 既定用法
  - 関連病名
  - よく使う / 最近使用 バッジ
- 候補を選んだ時点で用法・日数は仮入力する
- ただし自動確定はしない

## 処方セット

理想の最小仕様:

- セット名
- 診療科
- 構成薬剤
- 各薬剤の既定用法
- 既定日数
- 有効 / 無効

使い方:

- 管理者または医師が登録
- chart 画面でセットを選ぶ
- 展開前に差分確認
- 重複や禁忌は展開後に再チェック
