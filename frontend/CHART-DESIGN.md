## 0. 上位原則

1. **モダン SaaS 水準** (Notion / Linear / Vercel / Stripe) — レガシー EMR の多色・高密度・装飾過多は採用しない
2. **3 クリック以内で主要操作に到達** — 候補選択と遷移を分けない、頻度低い行為を初期タブにしない
3. **方針文書に矛盾を残さない** — 迷ったらどちらに寄せるか提案する

## 1. レイアウトの骨格 (App Shell + Pane Scroll)

### 1.1 全体スクロールは禁止

- App ルートは `h-screen overflow-hidden` 固定
- ヘッダー (AppHeader) は `flex-shrink-0`
- メインエリアは `flex-1 overflow-hidden` で 3 ペインを横並び

```
┌────────────────────────────────────────────────────────────────┐
│ AppHeader (sticky, flex-shrink-0)                              │
├──────────┬─────────────────────────────────┬──────────────────┤
│          │                                  │                  │
│  Patient │  Record Pane                     │  Order Pane      │
│  Pane    │  (中央: 記録)                    │  (右: 次の行動)   │
│  (左)    │                                  │                  │
│          │  独立スクロール                  │  独立スクロール    │
│  独立    │  内部に sticky 入力フォーム      │  内部に sticky    │
│  スク    │                                  │  タブヘッダー      │
│  ロール   │                                  │                  │
│          │                                  │                  │
└──────────┴─────────────────────────────────┴──────────────────┘
        固定        独立スクロール領域            独立スクロール領域
```

### 1.2 ペイン幅

| ペイン | 幅 |
|---|---|
| 左 (PatientPane) | `w-64` (256px) — リサイズ将来検討 |
| 中央 (RecordPane) | `flex-1` (可変) |
| 右 (OrderPane) | `w-80` (320px) |

幅未満の画面（タブレット縦・モバイル）は別レイアウト（責務外、Phase 後送り）。

### 1.3 各ペインのスクロール構造

- 各ペイン: `h-full overflow-y-auto`
- ペイン内 sticky ヘッダ（タブ・タイトル・入力フォーム等）は `sticky top-0 bg-card z-10`
- 多段スクロールは可（ペイン全体スクロール + 内部リスト独立スクロール）

## 2. 3 ペイン責務（WHO / WHAT / DO）

### 2.1 PatientPane (左 = WHO・不変情報)

**置く**:
- 患者基本情報（氏名・生年月日・年齢・性別・保険）
- アレルギー（赤系強調 1 箇所のみ）
- プロブレムリスト（慢性病名）
- 主治医・緊急連絡先

**置かない**:
- ❌ 受診履歴（時系列なので RecordPane へ）
- ❌ プロフィール編集（設定画面へ）
- ❌ オーダー操作（OrderPane へ）

**タブ使用**: タブで「基本情報 / 問題 / アレルギー / その他」を切替可能（カテゴリ排他で OK）。デフォルトタブは「基本情報」。

### 2.2 RecordPane (中央 = WHAT・記録)

**置く**:
- 上端 sticky:
  - 今日の SOAP 入力フォーム
  - バイタル・テンプレート選択
- スクロール領域:
  - 直近受診のカルテ → 過去カルテ → ... の連続タイムライン
  - 各カルテ: **記述本文 + 病名/サマリ** が主表示
  - 薬剤・検査・PMDA はインライン折り畳み（デフォルト閉じ）

**置かない**:
- ❌ オーダー操作（OrderPane へ）
- ❌ 患者プロフィール編集
- ❌ クリック式の日付タブ（時系列はスクロールで見せる）

**タブ使用しない**: 中央の時系列はスクロール一択。期間フィルタ（直近1週/1ヶ月/全期間）は sticky ヘッダー内のドロップダウンで提供。

### 2.3 OrderPane (右 = DO・次の行動)

**置く**:
- 今日のオーダーキュー
  - タブで処方/検査/画像/処置を排他切替（カテゴリ排他で OK）
  - タブヘッダーは sticky、その下のキューが独立スクロール
- セット展開・警告・PMDA short
- 確定アクション（→会計連携）

**置かない**:
- ❌ 過去カルテ閲覧（RecordPane へ）
- ❌ 患者基本情報（PatientPane へ）

**タブ使用**: 4タブ（処方/検査/画像/処置）は使用頻度高 + 排他なので OK。デフォルトは処方。

## 3. スクロール vs タブの使い分けルール

| 性質 | UI |
|---|---|
| 時系列・履歴・連続的なリスト | **スクロール** |
| 排他的カテゴリ・別行為への切替 | **タブ** |
| 副情報の一時表示（薬歴・検査詳細等） | **インライン折り畳み**（デフォルト閉じ） |
| 集中して読む長文（PMDA 添付文書全文・印刷プレビュー） | **モーダル** |
| 並列で見比べる（検査グラフ・他カルテとの並列） | **右ペインオーバーレイ (sheet)** ※限定使用 |

**禁忌**:
- 時系列・履歴をクリック式タブで隠す
- カルテ閲覧フローでモーダルを多用する（中断耐性が低い医療現場で文脈喪失を起こす）
- 右ペインを副情報ピークで潰す（DO 役割と競合）

## 4. 過去カルテアイテム (PastChartItem) の情報設計

### 4.1 主情報（常時表示）

1. 受診日 + 受診種別
2. **記述本文（SOAP の Assessment + Plan を中心に）**
3. **病名 / 診断**（その日に確定/更新されたもの）
4. **サマリ**（任意・要約があれば）

### 4.2 副情報（折り畳み・デフォルト閉じ）

折り畳みは `<details>` 風のトグルで：

- 薬剤（処方リスト）
- 検査結果
- PMDA 警告
- 画像オーダー
- バイタル詳細

トグルラベル例: `▶ 処方 4件 / 検査 2件 / 警告 1件`

### 4.3 副情報の展開先

- インライン展開がデフォルト
- 薬剤詳細 PDF や PMDA 全文は**モーダル**で開く（インラインだと冗長すぎる場合）
- 検査トレンドのグラフは**右ペインオーバーレイ (sheet)** で並列表示も可

## 6. タイポグラフィ・スペーシング

- 受診日見出し: `text-[18px] font-bold leading-snug`
- 病名タグ: `text-[12px] font-medium uppercase tracking-[0.05em]`
- 記述本文: `text-[14px] font-normal leading-normal` (1.5)
- 副情報トグル: `text-[13px] font-medium`
- ペイン間ギャップ: `gap-0`（境界線で分離 / 視覚ノイズ最小化）
- カード内パディング: `p-4` または `p-6`
- セクション間: `space-y-6` (24px)

詳細は [`CLAUDE.md`](CLAUDE.md) の "Font Size by Context" 表を参照。**新規コードでフォントサイズを推測しない**。

## 7. アクセシビリティ

- WCAG 2.2 AA 準拠（[`../docs/DESIGN_GUIDELINES.md`](../docs/DESIGN_GUIDELINES.md)）
- インタラクティブ要素はすべて 44×44px 以上
- アレルギー警告は色 + アイコン + テキストの 3 重表現
- 折り畳みトグルは `<button aria-expanded>` で実装
